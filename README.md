# Matatu Route Bot

A Telegram bot providing real-time information on Nairobi's Matatu routes, stages, and fares.

## Features
- Search by route number (e.g., 111, 46, 102).
- View key stages for each route.
- Get estimated peak and off-peak fares.

## Setup
1. Create a bot with @BotFather and get the token.
2. Set environment variable: `export BOT_TOKEN='your_token'`.
3. Run `npm install`.
4. Run `npm start`.
